# Shark 🦈

An AI that takes you from an idea to your first **10,000 users**: planning, coding, deploy, bug fixing, and launch.

*   **Five stages, one goal:** Plan → Code → Deploy → Bugs → Launch, tracked against a 10,000-user progress bar.
*   **Four agents:** Planner, Coder, Reviewer, Deployer — each with its own brief.
*   **Live preview:** paste or generate any single-file project and run it instantly.
*   **GitHub connection:** paste a personal access token (kept on the device only) and Shark lists your repos and helps you push.

Live: https://rameshkannan1472014-star.github.io/Shark-AI/

Built with plain HTML/CSS/JS. The AI brain is the free Pollinations endpoint with a graceful offline message; swap `brain` in `app.js` for your own key when ready.
